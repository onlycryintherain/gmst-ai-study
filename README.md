# gmst-ai-study

인공지능 일반 수행평가 대비 사이트 (`index.html` 한 파일, 설치 없이 브라우저로 열면 됨)

## 시험 구성
- **1과제 (20점) 개념 확인**: 설명을 보고 해당하는 명령어나 핵심 개념 답변 (인공지능 활동지 #1~#9-3, 활성화 함수)
- **2과제 (80점) 프로그래밍**: 최종본 소스 코드 빈칸 1~45 중 15문항 랜덤 출제
- 최종본 1페이지(명령어 보기 · 데이터 · 특성 · 타입)는 시험 중 참고 가능
- 기존 프린트물에 오탈자가 있어 내용은 PDF 기준으로 작성

## 기능
- 📖 **빈칸 암기장**: 클릭해서 가리기/펼치기, 시험처럼 랜덤 15개 가리기, 자주 틀린 빈칸만 가리기
- 🎯 **빈칸 실전**: 시험지 1페이지 재현 + 랜덤 15문제(80점 환산) / 약점 집중 / 구간별, Enter로 다음 빈칸, 함정 안내
- 📚 **활동지 이론 정리**: 활동지 전체 내용을 핵심어 가리기 방식으로 정리 (활성화 함수 비교표 포함)
- 🧠 **이론 퀴즈**: 실전형(설명 → 명령어·개념 주관식, 20점 환산), 약점 집중, 객관식 워밍업, 핵심어 빈칸
- 📊 **오답노트**: 풀이 기록은 브라우저(localStorage)에 저장
