활성화 함수(Activation Function)란? 신경망에서 입력 신호를 변환하여 비선형성을 부여하고, 모델이 더 복잡한 패턴을 학습할 수 있도록 도와주는 함수.

종류수식 / 특징출력 범위주요 특징 및 한계그래프 형태주요 용도
시그모이드
(Sigmoid)		$f(x) = \frac{1}{1+e^{-x}}$ 0 ~ 1 오차 역전파 시 기울기가 0에 수렴하는
[기울기 소실(Vanishing Gradient)] 문제 발생		 S자 곡선 이진 분류
(과거에 많이 사용)

[기울기 소실 문제 해결(완화)], 연산 효율 높음		 계단형
(음수 구간 0)		 은닉층
(현재 가장 많이 사용)
